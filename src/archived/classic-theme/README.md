# Classic theme (archived)

Snapshot of the site before the jellyfish redesign (October 2026): Roboto Mono on `#1d1e22`, a name-only header,
three paragraphs of copy, and the icon social row with hover attribution labels.

It is self-contained (relative imports only) and still type-checks and tests with the rest of the repo. To bring it
back, render `ClassicApp` from `src/main.tsx` in place of `App`. It relies on the Roboto Mono file in
`public/fonts/roboto-mono/`.
